# BuyOnBoard
Offline PWA application for onboard sales
# ✈️ BuyOnBoard - Aplicație PWA pentru Vânzări la Bord

Aplicație offline pentru gestionarea vânzărilor la bordul aeronavelor. Permite adăugarea produselor în coș, calcularea totalului în multiple valute și calcularea restului.

## 🚀 Caracteristici

- 📱 **Aplicație PWA** - Se instalează pe ecranul telefonului
- 📶 **Funcționează Offline** - Toate datele sunt salvate local
- 🛍️ **Gestionare Produse** - Vizualizare în Poze sau Listă
- 🛒 **Coș de Cumpărături** - Adăugare/eliminare produse
- 💰 **Multiple Valute** - EUR, MDL, USD, GBP
- 🧮 **Calculator Rest** - Calculează automat restul
- 🔄 **Actualizări Automate** - Buton de reîncărcare la actualizări

## 📋 Produse Incluse

Aplicația include 30 de produse:
- Sandwich-uri, Băuturi, Gustări
- Dulciuri, Băuturi alcoolice
- Jucării, Servicii

## 🛠️ Tehnologii Folosite

- HTML5 + CSS3
- JavaScript (Vanilla)
- PWA (Progressive Web App)
- Service Workers
- Local Storage
- GitHub Pages / Netlify
